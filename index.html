How to Use Botyy

Get started in a few simple steps.

Command:

/joinbot <botname> <autojump on/off>
  • 1. Install the mod on your main account (the one you play with).
  • 2. Run the command /joinbot <botname> <autojump on/off> in chat.
  • 3. The bot will join your current server and send a /tpahere request to you.
  • 4. The bot automatically accepts the teleport request — you're now ready to AFK together!

The bot will follow you and keep you company while you're away.
